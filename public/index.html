What it actually does

🔎

Settles arguments

Searches the web for stats, scores, prices and news, then answers in a sentence or two with sources. It's been reading the chat, so you don't have to re-explain what you were arguing about.

📍

Plans the outing

Say /plan dinner in Austin and everyone just talks. It pulls out who's free, budgets, dietary needs and accessibility — then returns three finalized options with booking links.

🤫

Knows when to shut up

It never replies unless spoken to. Ambient banter is read for context and answered with silence — because a bot that comments on every message is the thing this exists to eliminate.

Add it to your chat

Three ways to get its attention once it's in: @mention it, reply to it, or just start with "huddle,".

✈️

Telegram

  1. Message @BotFather → /newbot
  2. /setprivacy → your bot → Disable
  3. Add the bot to your group

Step 2 isn't optional — without it Telegram hides normal messages from bots.

🎮

Discord

  1. Developer Portal → New Application → Bot
  2. Enable Message Content Intent
  3. OAuth2 → invite it to your server

Same trap as Telegram — the intent is required.

💬

iMessage

  1. Grant your terminal Full Disk Access
  2. Run ENABLE_IMESSAGE=1 npm run bots
  3. It replies in your existing threads

Apple has no bot API — this relays through your own Mac, so messages send from your number.

WhatsApp has no group-bot API at all, so there's no honest way to do it. Paste an invite link there instead — it works everywhere.
