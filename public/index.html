What it actually does

🔎

Settles arguments

Searches the web for stats, scores, prices and news, then answers in a sentence or two with sources. It's been reading the chat, so you don't have to re-explain what you were arguing about.

📍

Plans the outing

Say /plan dinner in Austin and everyone just talks. It pulls out who's free, budgets, dietary needs and accessibility — then returns three finalized options with booking links.

🤫

Knows when to shut up

It never replies unless spoken to. Ambient banter is read for context and answered with silence — because a bot that comments on every message is the thing this exists to eliminate.

It tells you what it actually knows

Every line on a plan is labelled by where it came from. Solid green means we did the arithmetic from what your group said. Dashed means the catalog says so — and we haven't checked. Accessibility and dietary claims never get the green tick, because being wrong there hurts someone.

From dinner to a whole trip

The same brain that settles arguments plans the outing — and it scales from a Tuesday dinner to a group weekend away. Say the occasion, everyone talks normally in the chat, and it turns the usual spiral (“where?” “what time?” “is it accessible?” “that's too expensive for me”) into three finalized, bookable options.

🗓️

1 · Start it

/plan Maya's birthday dinner in Portland — or a night out, a team lunch, a weekend trip. Just name the occasion and the city.

💬

2 · Everyone just talks

“Free Sat after 5,” “~$25,” “my sister's vegetarian,” “grandma uses a walker.” It reads the chat, pulls out each person's constraints, and reacts ✅ — no nagging forms.

📍

3 · Get 3 bookable plans

It does the arithmetic — the overlap everyone's free, the cheapest ceiling, every dietary and access need — and returns three options with map, booking, and calendar links. Vote right in the chat.

Planning a bigger trip? The same flow handles it: dates instead of an evening, a city instead of a venue — and every option still carries the honest ✓ computed vs. ⌁ listed labels above, so no one books a place on a claim nobody checked.

Add it to your team in one click

No terminal, no API key, nothing to install. This instance is already running — click below, approve on the permission screen, and it's in your workspace. Great for a team channel: @mention it to settle a debate and it answers with sources.

It reads the channel for context but only replies when you @mention it — never chatty. Self-hosted, so your conversations stay on infrastructure you control.

Prefer to self-host? Run your own bot — about 10 minutes. Tap to expand.

You hold the keys and the bill, and nothing leaves your machine. Do it once and your bot serves every group you add it to. Deploy to Render does steps 1 and 3 for you.

1

Get it running

Clone the repo and install. The planner works with no API key at all; add one to unlock the part that answers questions. 

git clone https://github.com/prit6767/huddle
cd huddle && npm install
export ANTHROPIC_API_KEY=sk-ant-...   # optional
npm start                             # → localhost:3000

Leave that running. The badge in this page's header tells you which engine is live — a model name, or heuristic if there's no key.

2

Create the bot and get a token

Pick your platform. Each one has exactly one step people miss — it's called out in amber.

✈️

Telegram

  1. Message @BotFather → /newbot → copy the token
  2. /setprivacy → your bot → Disable
  3. Add the bot to your group
  4. Remove it and re-add it

Privacy mode is cached when the bot joins. Skip the re-add and it stays deaf to normal messages — which is the whole product.

🎮

Discord

  1. Developer Portal → New Application → Bot
  2. Reset Token → copy it
  3. Enable Message Content Intent
  4. OAuth2 → URL Generator → scope bot, then Send Messages, Read Message History, Add Reactions
  5. Open the generated URL to invite it

Without Message Content Intent, Discord delivers empty messages and the bot reads nothing.

💼

Slack

  1. api.slack.com/apps → Create New App
  2. Socket Mode → Enable → app-level token
  3. Add bot scopes, subscribe to message events
  4. Install to workspace → copy both tokens
  5. Invite it: /invite @YourApp

Socket Mode needs no public URL, so it runs inside a private network — and self-hosted, no conversation data leaves your infrastructure.

💬

iMessage

  1. System Settings → Privacy & Security → Full Disk Access
  2. Add your terminal app, then fully quit and reopen it
  3. Run npm run doctor to check every permission
  4. No token. For its own identity, sign Messages into a dedicated Apple ID — an email works, no phone number needed

Apple ships no bot API. This drives Messages on a Mac you own, so it only runs while that Mac is awake — and without its own Apple ID, replies send from your number.

3

Start the bot process

In a second terminal, with the token from step 2. It reads the same data as the web app, so a plan started in chat opens in the browser and back again. 

TELEGRAM_BOT_TOKEN=... npm run bots
DISCORD_BOT_TOKEN=...  npm run bots
ENABLE_IMESSAGE=1      npm run bots

Deployed somewhere public? Add HUDDLE_PUBLIC_URL=https://your-host so the links it posts are reachable by everyone else in the chat.

4

Talk to it

It reads everything for context but answers only when addressed. Four ways to get its attention:

  • @YourBot who won the game last night?
  • huddle, what's the exchange rate right now?
  • /ask is this restaurant still open
  • …or just reply to one of its messages

To plan something: /plan dinner in Austin, then everyone talks normally — it reacts ✅ as it picks up each person. /status shows who's answered, /go returns the three options. /usage shows what today cost, /forget drops the context it's holding.

WhatsApp has no group-bot API at all, so there's no honest way to do it — the unofficial workaround gets phone numbers banned. Paste a huddle's invite link into WhatsApp instead: it unfurls into a card and everyone taps through. Works in every chat app on earth, zero setup.
