◍ Huddle — Support

Huddle is an AI that lives in your group chat. Add it, @mention it with a question, and it answers — searching the web for anything current, so it's useful for settling a debate.

Using it

  • Invite it to a channel, then @mention it (or DM it) with your question.
  • It reads the channel for context but only replies when you address it.
  • It answers in a sentence or two, with source links when it searched the web.

Get help

  • Report a bug or ask a question: open an issue on GitHub.
  • Email: reach the maintainer at pritamavuthu2010@gmail.com.
  • See how it works: Huddle is open source — read the code.

Privacy

What Huddle does with your data is described on the privacy policy page. In short: it processes only the messages you address to it, keeps a small rolling context buffer, sends message text to Anthropic to generate answers, and never sells your data.
